# Rails blog

Блог за офіційним гайдом Getting Started (Rails): статті (CRUD), коментарі, `ActionMailer`-сповіщення про коментарі, Turbo (форми, `turbo_confirm`, `turbo_frame_tag`).

## Відео сетапу
Запишіть: `asciinema rec setup.cast` → `./setup.sh`, потім конвертуйте у `public/setup.mp4`
(або запис екрана). Відео показується на головній сторінці (`app/views/articles/index.html.erb`).
